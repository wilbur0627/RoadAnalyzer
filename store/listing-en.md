# RoadAnalyzer — Baccarat Road Analysis

## Short Description (132 chars max)
Select the baccarat road on any page and analyze it in real time. 5 road types + prediction. For entertainment only.

## Detailed Description

### Region Capture
Drag a box around the road chart once. RoadAnalyzer captures only that area and sends it to our analysis server to read the results. While that tab is the active tab, it checks the area again every 10 seconds, and uploads it only when it has changed. After the road chart fills up and scrolls, hands that scroll out of view are still counted. Start capturing when a new shoe begins to record every hand of it.

### 5 Road Types
- Big Road (大路) — The primary road showing banker/player sequences
- Bead Plate (珠盤路) — Sequential result display
- Big Eye Boy (大眼仔路) — Derived road showing pattern consistency
- Small Road (小路) — Derived road with 2-column offset
- Cockroach Pig (曱甴路) — Derived road with 3-column offset

### Smart Prediction Engine
Our analysis engine combines multiple signals:
- Streak analysis with historical comparison
- Frequency tracking
- Pattern recognition (ping-pong, doubles, triples, increasing streaks, zigzag) — Premium
- Derived road consensus analysis — Premium

Predictions start after 10 hands, and confidence is scaled down until there are 30 hands of data. Confidence is capped at 75% to be transparent — no tool can guarantee results.
